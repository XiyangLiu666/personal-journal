如何把更新放到 GitHub？
  1. 修改内容后，点“预览草稿”查看效果。
  2. 点“导出 content.json”，保留下载文件名为 content.json。
  3. 在 GitHub 仓库打开 data 文件夹，选择 Add file → Upload files，上传该文件并提交。
  4. 照片先上传到仓库 assets 文件夹，在这里填写路径，例如 assets/my-photo.jpg，然后再次导出内容。
  5. 等待 GitHub Actions 部署完成，再刷新正式网站。

此编辑页不连接 GitHub，也不是登录后台。公开网站上的内容和图片都能被访客读取，请只发布适合公开的信息。
