第一次使用：连接 GitHub（每台设备只需一次）
  1. 登录 GitHub 后打开 创建密钥页面 ↗。
  2. Token name 随便填，例如 journal；Expiration 选一个期限，例如 1 年。
  3. Repository access 选 Only select repositories，然后选 personal-journal。
  4. Permissions 中添加 Contents，设为 Read and write。想看到“网站已更新”的提示，可再添加 Actions 设为 Read-only。
  5. 点 Generate token，复制以 github_pat_ 开头的密钥，粘贴到下面并点连接。

密钥只保存在这台设备的浏览器里，不会出现在网站或仓库中。拿到这台设备浏览器的人也能用它发布，公用电脑用完请点断开。
